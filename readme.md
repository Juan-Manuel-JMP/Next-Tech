## 🚀 Sobre el proyecto

**Next Tech** es una tienda online enfocada en productos tecnológicos de última generación.

El proyecto fue desarrollado con una interfaz moderna, limpia y completamente responsiva, buscando ofrecer una experiencia de compra sencilla y atractiva.

La aplicación permite explorar diferentes productos, filtrarlos por categoría, visualizar información detallada y gestionar un carrito de compras.

> 💡 **Objetivo:** crear una experiencia de e-commerce moderna combinando diseño, funcionalidad y una buena experiencia de usuario.
